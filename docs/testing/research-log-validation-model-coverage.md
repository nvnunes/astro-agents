# Research-Log Validation Model Coverage

This index maps the maintained mechanical-validation contract to its owning
implementation and representative tests. The normative behavior remains in
the [mechanical-validator specification](../research-log-mechanical-validator-spec.md);
this document owns coverage navigation, not a second copy of the contract.

Every row names a production owner and an exact test scenario. A contract
change must update the specification, the owning implementation, and the
corresponding row or test. The complete gate remains in
[Research-Logging Validation](research-logging.md). Passing commands and
per-refactor equivalence evidence belong in the active implementation plan,
not here.
