# AGENTS.md Writing

Use this skill for `AGENTS.md` files.

Read `references/agents-md.md` before writing or revising an `AGENTS.md` file. Pair with `$prompt-writing` only when broader reusable prompt discipline is needed; keep `$agents-md-writing` primary for `AGENTS.md` scope, workflow, and instruction-layering behavior.

Keep `AGENTS.md` focused on operational instructions that should affect a fresh agent thread: scope, workflow, important source-of-truth links, working rules, and validation expectations. Move durable explanation and design rationale into project docs.

When reviewing an `AGENTS.md`, check that it has a clear owner, does not duplicate deeper docs, points to narrower prompts or skills when appropriate, and states local exceptions explicitly.
