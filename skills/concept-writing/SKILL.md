# Concept Writing

Use this skill for concept and foundation documents.

Pair with `$technical-writing` for common prose discipline, then read `references/concept.md` for concept-document expectations.

Make the central idea explicit, separate current understanding from open questions, and preserve the reasoning that later implementation or architecture docs will need. Do not over-specify implementation detail unless the concept already depends on it.
