# Pubify Pubs Figures

Use this reference for `pubify-pubs` figure layouts, `FigureResult`, `panel(...)`, and publication figure export options.

## Layouts

`layout` selects the manuscript figure grid and the export geometry used for each generated figure panel. Use the layout that matches how the figure should appear in TeX, then use `caption_lines`, `subcaption_lines`, and export options only for local adjustment.

| Layout | Grid | Use |
| --- | --- | --- |
| `one` | 1 x 1, full page | One tall single-panel figure. |
| `onewide` | 1 x 1, wide | One normal-width single-panel figure. |
| `two` | 1 x 2, stacked | Two vertical panels. |
| `twowide` | 2 x 1, wide | Two side-by-side panels. |
| `three` | 1 x 3, stacked | Three vertical panels. |
| `threewide` | 3 x 1, wide | Three side-by-side panels. |
| `four` | 2 x 2, stacked | Four panels. |
| `six` | 2 x 3, stacked | Six panels in two columns and three rows. |
| `sixwide` | 3 x 2, stacked | Six panels in three columns and two rows. |
| `nine` | 3 x 3, stacked | Nine panels. |
| `twelve` | 3 x 4, stacked | Twelve panels in three columns and four rows. |
| `twelvewide` | 4 x 3, stacked | Twelve panels in four columns and three rows. |
| `fifteen` | 3 x 5, stacked | Fifteen panels. |
| `sixteen` | 4 x 4, stacked | Sixteen panels. |
| `twenty` | 4 x 5, stacked | Twenty panels. |

`caption_lines` and `subcaption_lines` reserve real vertical space in the exported figure geometry. Set them to match the manuscript caption and subcaption structure that will be used in TeX.

Use `force_width`, `force_height`, or `force_aspect` only after choosing the correct layout. They tune export size and aspect ratio; they do not replace the layout. `force_width` is not supported for wide layouts.

Use `pubs <publication-id> figure <figure-id> latex [subcaption]` to generate the matching TeX scaffold. Include `[subcaption]` when the manuscript should use panel-level subcaptions.

## Figure Returns And Panels

A publication plot function may return a Matplotlib `Figure`, `Axes`, or a sequence of figures or axes. Use `pubify_pubs.FigureResult` when the figure needs explicit layout, captions, subcaptions, or per-panel options:

```python
from pubify_pubs import FigureResult
from pubify_pubs.export import panel

return FigureResult(fig, layout="onewide")
return FigureResult([fig1, fig2], layout="twowide")
return FigureResult(
    panel(fig, subcaption_lines=2),
    layout="onewide",
    caption_lines=2,
)
```

A panel is one exported part of a figure result. Multi-panel publication figures export as separate generated PDFs under `autofigures/`, and the manuscript uses the LaTeX scaffold generated by `pubs <publication-id> figure <figure-id> latex [subcaption]`.

Use `panel(...)` only when one panel needs its own export options or subcaption settings. Prefer figure-level `metadata` when every panel should share the same setting. See the API Reference below for supported options.

For figures produced by external helpers, make publication-specific changes inside the `plot_` function or use `prepare_export` when the change should happen only immediately before export. See `figure-export.md` for more detail.

For figure-specific export cleanup, attach `prepare_export` through `FigureResult(..., metadata={...})`:

```python
return FigureResult(fig, layout="onewide", metadata={"prepare_export": _prepare_export})
```

When plotting code creates text and the exported figure needs publication typography, use `ctx.rc`:

```python
@figure
def plot_example(ctx):
    with ctx.rc:
        fig = build_plot()
    return fig
```

## API Reference

### FigureResult

`pubify_pubs.FigureResult(...)` accepts:

| Option | Use |
| --- | --- |
| `panels_or_panel` | Matplotlib `Figure`, `Axes`, sequence of figures or axes, `panel(...)`, or sequence of `panel(...)` values. |
| `panels` | Keyword form of `panels_or_panel`; do not pass both. |
| `layout` | Named LaTeX layout; see Layouts above. |
| `caption_lines` | Number of manuscript caption lines used for figure layout; must be at least 1 when set. |
| `subcaption_lines` | Number of subcaption lines used for every panel unless a panel overrides it; must be at least 1 when set. |
| `metadata` | Publication export options applied to every panel unless panel options override them. |

### Panel

`pubify_pubs.export.panel(...)` accepts:

| Option | Use |
| --- | --- |
| first argument | Panel figure or axes. |
| `subcaption_lines` | Panel-specific number of subcaption lines used for layout; overrides the `FigureResult` default for that panel. |
| publication export options | Any option from the Publication Export Options tables below; applies to that panel only. |

### Publication Export Options

These options may be used in `FigureResult(..., metadata={...})` or as `panel(...)` keyword options.

Use `extra_rcparams` in `pubify-mpl-defaults` for publication-wide export rcParams, in `FigureResult(..., metadata={...})` for one logical figure, or in `panel(...)` for one panel.

#### Sizing And Rendering

Use these when the exported figure needs explicit size or render control.

| Option | Use |
| --- | --- |
| `dpi` | Render DPI. |
| `force_aspect` | Force exported height/width aspect ratio. |
| `force_height` | Cap exported height in inches. |
| `force_width` | Force exported width in inches when the layout supports it. |

#### Visibility And Style

Use these when the source figure is right, but the prepared export needs precise final adjustment or publication-specific style handling.

| Option | Use |
| --- | --- |
| `prepare_export` | Callback that mutates the prepared export figure immediately before save. |
| `extra_rcparams` | Extra Matplotlib rcParams for export. |
| `hide_annotations` | Hide annotations during export. |
| `hide_cbar` | Hide colorbars during export. |
| `hide_grid` | Hide grid lines during export. |
| `hide_labels` | Hide axis labels during export. |
| `hide_tick_labels` | Hide tick labels while keeping ticks. |
| `hide_ticks` | Hide ticks and tick labels during export. |
| `keep_titles` | Preserve Matplotlib titles during export. |

#### Rasterization And Copy Behavior

Use these only when export mechanics need tuning.

| Option | Use |
| --- | --- |
| `skip_clone` | Export without cloning the Matplotlib figure; use only when cloning fails or is inappropriate. |
| `skip_rasterize` | Disable automatic rasterization for vector outputs. |
| `rasterize_image_pixel_threshold` | Auto-rasterize images above this pixel count. |
| `rasterize_line_vertex_threshold` | Auto-rasterize lines above this vertex count. |
| `rasterize_scatter_threshold` | Auto-rasterize scatter artists above this point count. |
