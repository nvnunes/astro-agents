# README Writing

Use this skill for `README.md` and folder-level README files.

Pair with `$technical-writing`, then read `references/readme-md.md`. Pair with `$project-docs-writing` only when the README needs source-of-truth or documentation-surface judgment.

Keep README files oriented toward fast human entry: what this is, when to use it, where to go next, and which docs own durable details. Avoid turning a README into the full source of truth when a narrower doc owns the detail.
