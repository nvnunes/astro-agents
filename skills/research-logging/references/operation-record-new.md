# Record New Entry Instructions

Use this file when recording work that needs a new entry.

`Record New` creates one dated entry folder and entry document, then records the material the user asked to preserve.

## Procedure

1. Locate the log summary `<log>.md` and matching `<log>/entries/` folder.
2. Choose the next stable log-local entry ID and descriptive topic slug using `skills/research-logging/references/file-entry-naming.md`.
3. Create `<log>/entries/<start-date>-<entry-id>-<descriptive-topic-slug>/<entry-id>.md` and preserve the record using `skills/research-logging/references/file-entry.md`.
4. Apply `skills/research-logging/references/operation-record-content.md` for shared content guidance.
