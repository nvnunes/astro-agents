# Record Operation Instructions

Use this file when the user wants to log, record, keep track, document, save, note, add to the research log, continue an entry, or preserve what happened.

`Record` is the default operation when the user is adding or revising entry content.

## Routing

- New entry, new topic, or no matching existing entry: read `skills/research-logging/references/operation-record-new.md`.
- Existing entry continuation, revision, or user-specified entry path or ID: read `skills/research-logging/references/operation-record-existing.md`.

If multiple existing entries could match, ask before editing. If the user asks to update current understanding in `<log>.md` rather than preserve dated work in an entry, use `skills/research-logging/references/operation-summarize.md` instead.
