# Technical Writing

Use this skill for technical prose work and as the base writing discipline for narrower writing skills.

Read `references/base.md` before writing, revising, or reviewing human-facing technical documents unless a narrower active writing skill already carries a stricter local rule.

When composing with a narrower writing skill, apply this skill first for common prose discipline, then apply the narrower skill's reference for document-specific constraints.
